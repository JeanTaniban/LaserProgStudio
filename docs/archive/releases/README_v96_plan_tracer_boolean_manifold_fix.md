# LaserProg v96 — Plan Tracer boolean manifold fix

## User-visible fixes

- Global **Boolean Subtract** now accepts closed volumes generated by Plan Tracer 2D when `manifold3d` requires geometric seam cleanup.
- A target completely consumed by the cutter is now removed from the scene instead of being reported as an invalid/open volume.
- Boolean failures no longer append the misleading generic statement that every failure means an open solid.
- When a real manifold problem remains, the dialog reports which input failed and includes indexed boundary/non-manifold counts plus the `manifold3d` status.

## Boolean input validation

The old pipeline checked only triangle-index edge counts. A mesh can pass that check but still be rejected after coincident geometric vertices are merged. The new pipeline:

1. preserves the fast path for normal primitives and valid Plan Tracer solids;
2. constructs the `manifold3d.Manifold` and checks `status()` and `is_empty()` explicitly;
3. retries invalid inputs with a conservative weld, duplicate-triangle removal and winding repair;
4. uses optional repair backends only as a final fallback;
5. reports the exact failed attempt if the input still cannot become a valid manifold.

## Complete subtraction

A valid difference may contain no triangles when the cutter fully covers the target. This is now represented by `BooleanEmptyResult`. The global subtract controller interprets it as a successful removal of the target and adjusts the cutter selection index after deleted targets are removed.

## Diagnostics

When **Diagnostics debug mode** is enabled, boolean operations write:

```text
 diagnostics/boolean_debug.jsonl
```

The trace contains input topology summaries, manifold status, repair attempts, empty-result classification and successful result counts. No disk writes occur in normal mode.

## Validation

- primitive minus Plan Tracer volume;
- Plan Tracer volume minus Plan Tracer volume;
- complete consumption of a primitive by a Plan Tracer cutter;
- scene removal and cutter-index preservation after complete consumption;
- cylinder/cone boolean compatibility;
- Plan Tracer closed-solid generation;
- mask-relief merge policy;
- Plan Tracer New Sketch preservation tests.
