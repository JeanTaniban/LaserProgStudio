# Pass70 — Sober modern UI refinement

This pass tones down the previous visual refresh and moves LaserProg Studio toward a more sober, modern, and premium desktop look.

## Design direction
- Charcoal / graphite base.
- Soft slate-blue accents instead of bright laser colors.
- Reduced gradients and calmer contrast.
- A more understated scene-tab system inspired by modern productivity software.

## UI updates
- Reworked global palette for a classier long-session feel.
- Softer active/hover states across buttons and toolbar items.
- More neutral menus, status bar, scrollbars, and splitters.
- Cleaner inputs and panels with less visual noise.
- Scene tabs remain readable and premium without the previous sci-fi feel.

## Notes
- This pass intentionally decouples the UI from the current logo.
- A future logo can now be redesigned to match this calmer UI language.
