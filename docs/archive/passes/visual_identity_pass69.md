# Pass69 — Visual identity refresh

This pass gives LaserProg Studio a stronger branded visual identity aligned with the new logo.

## Design direction
- Dark deep-navy foundation inspired by the logo frame.
- Laser-green accent color inspired by the beam and engraving highlight.
- Professional long-session readability with higher contrast and calmer panel surfaces.
- Chrome-like scene tabs integrated into the same visual language.

## UI updates
- Refined global stylesheet across the full app.
- Better button hierarchy and stronger hover/checked states.
- Branded menu bar, menus, status bar, scrollbars, sliders, splitters and tooltips.
- Cleaner cards/panels for toolbox and controls.
- Brighter active scene tabs and interaction affordances.
- Fusion application style enabled for more consistent Qt rendering across Windows setups.

## Notes
- This pass focuses on appearance and interaction comfort without changing the main workflows.
- Existing functionality remains compatible with the scene/project architecture already in place.
