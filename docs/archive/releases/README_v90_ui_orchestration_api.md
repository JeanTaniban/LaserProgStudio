# LaserProg v90 — UI Orchestration API

This version integrates the reusable UI orchestration foundation for tutorials, contextual errors and ambiguous workflows.

Highlights:

- semantic UI anchor registry;
- semantic event bus;
- dimming, spotlight and callout scenes;
- lifetime and click/event exit policies;
- priority, suspension and resumption;
- immutable system/tutorial UI layouts;
- editable user layout presets;
- restricted UI-only actions;
- debug-gated orchestration diagnostics;
- first real use for unfinished-tool conflicts and selection errors.
